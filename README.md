# Core-Mind
Core-Mind es una plataforma web desarrollada con el propósito de demostrar y potenciar mis capacidades técnicas como programador. Este proyecto nace de la necesidad de consolidar mis conocimientos y servir como carta de presentación ante el mundo laboral.

En este espacio, no solo demuestro mi dominio de herramientas modernas, sino también mi enfoque estratégico para la resolución de problemas mediante la implementación de algoritmos eficientes y una arquitectura limpia. Core-Mind es el reflejo de mi profesionalismo, capacidad de aprendizaje y compromiso con la calidad de software.

# Tecnologías Utilizadas
La selección del stack tecnológico se realizó priorizando el rendimiento, la escalabilidad y la mantenibilidad a largo plazo:

Astro: Utilizado como framework principal para garantizar una carga ultrarrápida mediante su arquitectura de islas y generación de sitios estáticos (SSG).

Tailwind CSS: Para un diseño moderno, responsivo y altamente optimizado, eliminando el CSS innecesario en producción.

Docker: Implementado para la contenerización de la aplicación, asegurando un entorno de despliegue consistente y reproducible.

Infraestructura VPS: Gestión de servidor propio para el despliegue y administración del ciclo de vida del proyecto.

## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run preview`         | Preview your build locally, before deploying     |
| `npm run astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `npm run astro -- --help` | Get help using the Astro CLI                     |
